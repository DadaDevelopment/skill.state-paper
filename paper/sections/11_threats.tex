\section{Threats to validity}
\label{sec:threats}

\paragraph{Implementation and selection.}
The findings concern specific implementations, not structured memory in
general. Complete execution-source snapshots, generation settings, and
prompt traces are unavailable for independent replay. The model-written
release specifies inclusion rules, but their prospective timing is not
independently established. The hybrid collector description leaves
budget-related exclusions ambiguous, so outcome-dependent selection cannot
be ruled out. Conditions were not demonstrably balanced over execution
time and provider route.

\paragraph{Measurement and inference.}
Verifier-defined success measures benchmark completion rather than memory
quality in isolation. The available retention parameter does not establish
identical message semantics across implementations. Reference-tariff cost
and reported cost are distinct accounting conventions, and neither
includes all discarded attempts. Repeated tasks, outcome-conditioned
resource subsets, and exploratory multiple comparisons limit statistical
interpretation. The reported intervals do not establish representative
task sampling, and the hybrid aggregates do not support the same
task-level uncertainty analysis.

\paragraph{Generalization.}
The evaluation uses one model and coding-agent configuration on a limited
task collection. Schema adaptation used that same collection. Results need
not transfer to other models, state writers, retrieval mechanisms, or
workloads near a context-window limit. The missing history-only control
prevents a claim that state and recent history are complementary. No
validated trace-level analysis identifies a causal explanation for the
observed deficits.
