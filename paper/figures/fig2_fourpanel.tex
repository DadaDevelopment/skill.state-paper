\caption{Characterising structured state memory on \EOneTasks{} coding tasks,
\EOneRuns{} runs. \textbf{(a)} Solve rate with Wilson intervals; the control
solves \SolveBase{} against \SolveTailZero{} for the published configuration.
\textbf{(b)} Paired disagreement against the same-trial control -- only
discordant tasks carry information, and they are overwhelmingly one-sided at
$k{=}0$. \textbf{(c)} Net tasks lost, split at the control's median horizon:
the deficit \emph{widens} on long tasks, inverting the argument for the method.
\textbf{(d)} At equal outcome the published configuration halves the peak
prompt and multiplies cost by \CostRatioTailZero. Restoring six exchanges
($k{=}6$) returns capability to parity while staying below the control's cost.}
\label{fig:fourpanel}
