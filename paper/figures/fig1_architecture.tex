\caption{The two context policies of Algorithms~\ref{alg:transcript}
and~\ref{alg:state}. \textbf{Left:} the transcript runtime appends every
exchange, so the prompt grows with the episode (Eq.~\ref{eq:ctx-transcript})
and eventually meets the context window. \textbf{Right:} the state runtime
carries a validated state block and, at $k{=}0$, no history at all
(Eq.~\ref{eq:ctx-state}); its prompt is bounded independently of $t$. Both
discard intermediate reasoning. The bounded prompt is the published benefit.
What the diagram cannot show is the quantity this paper measures: bounding
$|C_t|$ does not bound the information the task requires, so the agent
re-acquires it through tool calls, inflating the realised horizon
(Eq.~\ref{eq:horizon-inflation}) at no cost visible to any prompt-size metric.}
\label{fig:architecture}
